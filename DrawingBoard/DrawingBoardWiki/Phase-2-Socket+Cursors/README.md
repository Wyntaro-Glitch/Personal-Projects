# Phase 2: Socket Connection

Real-time collaboration using Socket.io.

## Files

- `Phase-2.1-Socket-Server.md` - ✅ Server setup
- `Phase-2.2-Socket-Client.md` - Client connection
- `Phase-2.3-Broadcast-Strokes.md` - Send/receive strokes
- `Phase-2.4-Remote-Cursors.md` - Show cursors
- `Phase-2.5-User-Management.md` - Track users

## Quick Start

1. Install dependencies:
   ```bash
   cd server && npm install socket.io
   cd client && npm install socket.io-client
   ```

2. Follow phases in order

3. Test with two browser tabs
